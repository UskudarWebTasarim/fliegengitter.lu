# Fliegengitter.lu - Premium Insektenschutzlösungen

Professionelle Fliegengitter Fenster und Insektenschutzlösungen für Luxemburg und Europa. Maßgefertigte Produkte mit professioneller Montage.

## 🚀 Features

- **Bilingual Support**: Deutsch und Türkçe
- **Modern Design**: Next.js 15 mit TypeScript und Tailwind CSS
- **Responsive**: Optimierte Darstellung auf allen Geräten
- **SEO Optimized**: Schnelle Ladezeiten und bessere Suchmaschinenplatzierung

## 🛠️ Tech Stack

- **Framework**: Next.js 15.5.15
- **Language**: TypeScript
- **Styling**: Tailwind CSS
- **Icons**: Lucide React

## 📦 Installation

```bash
npm install
```

## 🏃 Development

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
